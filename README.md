# مسار — تطبيق التحضير لامتحان الكفاءة المهنية

مشروع Flutter حقيقي وكامل. الكود جاهز، لكنه يحتاج منك تشغيله على حاسوبك (لا يمكن تشغيله من هنا).

## 1. تثبيت الأدوات المطلوبة (مرة واحدة فقط)

1. **Flutter SDK**: حمّله من https://docs.flutter.dev/get-started/install (اختر نظام التشغيل عندك: Windows / macOS)
2. **Android Studio**: حمّله من https://developer.android.com/studio (يوفر لك محاكي هاتف Android للتجربة)
3. بعد التثبيت، افتح Terminal (أو cmd) واكتب:
   ```
   flutter doctor
   ```
   هذا الأمر يخبرك إذا كان كل شيء مثبت بشكل صحيح، ويعطيك تعليمات لإصلاح أي نقص.

## 2. تشغيل المشروع

1. افتح مجلد `masar_app` هذا داخل **Android Studio** (File > Open)
2. انتظر حتى ينتهي التحميل التلقائي للحزم، أو افتح Terminal داخل Android Studio واكتب:
   ```
   flutter pub get
   ```
3. شغّل محاكي هاتف Android من Android Studio (Device Manager > تشغيل أي جهاز افتراضي)
   - أو وصّل هاتف Android حقيقي بكابل USB مع تفعيل "وضع المطور" و"تصحيح USB" فيه
4. اضغط زر التشغيل (▶) في Android Studio، أو اكتب في Terminal:
   ```
   flutter run
   ```

بعد دقيقة أو دقيقتين سيفتح التطبيق مباشرة على المحاكي أو هاتفك.

## 3. بنية المشروع

```
lib/
  main.dart              نقطة انطلاق التطبيق
  theme/app_theme.dart   الألوان والخطوط
  models/                نماذج البيانات (سؤال، مادة)
  data/                  بنك الأسئلة وقائمة المواد (حالياً بيانات تجريبية)
  screens/               الشاشات الأربع: الرئيسية، المادة، الاختبار، النتائج
  widgets/                عناصر واجهة قابلة لإعادة الاستخدام
```

## 4. الخطوات التالية المهمة قبل الاستخدام الفعلي

- **توسيع بنك الأسئلة**: عدّل الملف `lib/data/questions_data.dart` وأضف المزيد من الأسئلة (حالياً 39 سؤالاً، أغلبها مبني على وثائق المنهاج الرسمية التي زودتني بها). المطلوب دائماً: مراجعة أستاذ أو مفتش تربوي لدقة المحتوى الجديد.
- **ملفات المراجعة الحقيقية**: أضفت 4 ملفات PDF حقيقية إلى `assets/review_files/` (دليل اللغة العربية م1، دليل فضاء النشاط العلمي م1، مفاهيم النشاط العلمي، ملخص المنهاج الدراسي). تُفتح تلقائياً بالضغط على المستوى/المادة المطابقة داخل التطبيق. لإضافة ملفات جديدة: ضع الملف في هذا المجلد، وأضف سطراً في `lib/data/review_files_data.dart` يربطه بالمادة/المستوى المناسب.
- **شعار الوزارة الرسمي**: أضف صورة الشعار إلى مجلد جديد `assets/images/ministry_logo.png`، ثم فعّل السطرين المعلَّقين في `pubspec.yaml`، واستبدل النص المؤقت "وت" في `lib/screens/home_screen.dart` بـ `Image.asset('assets/images/ministry_logo.png')`.
- **قاعدة بيانات حقيقية**: حالياً الأسئلة مكتوبة مباشرة في الكود (ثابتة). لإضافة/تعديل الأسئلة بدون إعادة نشر التطبيق، يُنصح بربطه لاحقاً بخدمة مثل Firebase.
- **النشر في المتاجر**: يتطلب حساب مطور Google Play (25$ مرة واحدة) و/أو حساب Apple Developer (99$ سنوياً) لنشره في App Store.
